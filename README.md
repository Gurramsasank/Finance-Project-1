# FinTrack

FinTrack is a personal finance manager web app built with HTML, CSS, and JavaScript. It helps users track income, expenses, monthly budgets, and overall savings in a simple dashboard.

## Features

- Dashboard overview with total balance, income, expenses, and savings
- Add, edit, and delete financial transactions
- Filter transactions by type and category
- Monthly budget tracking per category
- Expense category visualization using Chart.js
- Dark mode toggle
- CSV export for transactions
- Responsive design for desktop and mobile screens

## Tech Stack

- HTML
- CSS
- JavaScript
- Chart.js

## Project Structure

- `index.html` – app layout and UI structure
- `style.css` – styling and responsive design
- `script.js` – application logic, transactions, budgets, charts, and theme handling

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Gurramsasank/Finance-Project-1.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

You can also run it using a local web server if you prefer:

```bash
python -m http.server
```

Then open `http://localhost:8000` in your browser.

## Usage

- Click the `+ Add Transaction` button to record income or expenses.
- Navigate between Dashboard, Transactions, and Budgets.
- Set monthly budgets for categories such as Food, Bills, Shopping, and Health.
- Use filters and search to find specific transactions quickly.
